# المحتويات — مستعرض فهرس الملفات

موقع ثابت (HTML + JavaScript) يعرض هيكل المجلدات والملفات وأحجامها وتواريخها للاطلاع فقط. لا يحمّل الملفات ولا يعرض معاينات لها.
يعمل بدون إنترنت: ملف التنسيق والخطوط محليان داخل `assets/`.

## تحديث الفهرس

على جهازك:

```bash
python scan_catalog.py "D:\Library" "E:\Movies"
# أو لعرض محتويات مجلد مباشرة بدون مجلد الجذر:
python scan_catalog.py "D:\Library" --no-root-folder
# استثناء أنماط إضافية:
python scan_catalog.py "D:\Library" --exclude "*.bak" "Backup*"
```

سيُنشئ `catalog.json`. ارفعه إلى المستودع (commit + push) فيتحدّث الموقع لكل الزوار.

السكربت يتجاهل الملفات المخفية والروابط الرمزية ومجلدات النظام، ويكمل المسح إذا تعذّرت قراءة عنصر.

## خلفية الموقع

- **لكل الزوار:** ضع الصورة في المستودع (مثلاً `bg.jpg`) وعدّل `site.json`:

  ```json
  { "background": "bg.jpg", "overlay": 0.75, "blur": 6 }
  ```

  `overlay` قوة التعتيم فوق الصورة (0.2 – 0.95)، و`blur` تغبيش الأسطح بالبكسل (0 – 16).
- **للزائر نفسه:** زر الصورة في الشريط العلوي يتيح اختيار صورة من الجهاز (تُحفظ في متصفحه فقط)، أو إلغاء الخلفية، أو ضبط التعتيم والتغبيش.

## الوضع الليلي

هو الافتراضي، ويحفظ المتصفح اختيار الزائر إن بدّله.

## الروابط

كل مجلد له رابط مباشر مثل `#/اسم المجلد/المجلد الفرعي`، وزر الرجوع في المتصفح يعمل بين المجلدات.

## تعديل التصميم (اختياري)

ملف التنسيق `assets/style.css` مبني مسبقاً ومرفوع، فلا حاجة لأي بناء للنشر. إذا عدّلت الألوان أو الأصناف في `index.html` أو `src/input.css`:

```bash
npm install
npm run build
```

## النشر

أي استضافة ثابتة: GitHub Pages أو Vercel أو Cloudflare Pages، من جذر المستودع.
افتح الموقع عبر خادم (مثلاً `python -m http.server`) وليس بالنقر المزدوج على الملف، لأن المتصفح يمنع قراءة `catalog.json` من `file://`.
